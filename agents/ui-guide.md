# UI Guide

Build product UI inside the existing dashboard shell unless the product requires a public surface.

## Defaults

- Keep operational screens dense, clear, and calm.
- Use buttons for commands and icon buttons for common actions.
- Use cards only for repeated items, forms, and bounded panels.
- Include loading, empty, and error states.
- Keep copy concise and product-specific.

## Routes

- Product dashboard: `apps/web/app/dashboard`
- Billing: `apps/web/app/settings/billing`
- Settings: `apps/web/app/settings`
- Public marketing or landing pages: `apps/web/app`
